## 发现与最小修正

已确认：`RemoteCompletionSettings.isPaused` 直接读取布尔偏好，缺失键被解释为 false；因此空白配置下在线补全显示开启，虽然尚未配置任何服务。新增回归先失败，证明该现象存在于设置默认值，而非窗口控件缓存。

修正：仅当**没有在线开关偏好，且没有已配置标记**时，初始化持久化在线关闭。保存服务不会单独翻转这个选择；从首页明确开启而进入配置，仍由既有窗口在保存成功后启用并返回首页。已有明确开关始终优先；已配置但没有开关键的旧用户保持原有隐式开启，不写入新键。

这里以配置状态和已保存选择判断默认行为，不宣称准确识别了“新安装用户”。本机补全默认行为、应用联网授权、历史选择和提示策略未改。首页仍是两个开关，没有新页面或新增步骤。

| 保存失败 | 开关保持关闭、配置未成功、草稿保留 |
| 从首页启用后保存成功 | 配置持久化，在线开启，本机保留开启，返回首页；重建设置对象后保持 |
| 只保存服务 | 不自动开启在线 |
| 既有用户 | 已配置/未配置 × 明确开/关均保留；已配置而没有偏好键的旧行为保留 |

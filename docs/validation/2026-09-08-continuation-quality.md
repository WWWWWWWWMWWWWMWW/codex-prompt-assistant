# 续写语义与格式边界：2026-09-08

## 范围与结论

本轮依据用户最新要求，提前处理 M2 的一个有界质量工作包，不代表 M0 全部门禁完成，也不启动 M1 整体拆分。基线为 clean `2d94b2d`；新提示契约为 `2026-09-08.2`。源码、自动验证、模型语义和实机展示分别记录。

已确认：旧实现有单行/25–60 字提示、64 token 本地上限、90 字整条拒绝、换行停止与多行拒绝；表达候选没有共同显示质量门。这些机制会压缩续写、破坏结构兼容，并让完整句继续接上通用要求。

已修复的确定性边界：

- 所有显示来源（表达、缓存重定位、本地、远程）经过相同的重复/回应/格式检查。显示阶段只验证，不改写文字，保证接受的文本与预览一致。
- 完整句末且没有新的未完成单元时停笔。正文中部因目前没有右侧生成上下文，保守停笔；不假装支持填充中部语法。
- 未闭合引用、占位符、链接、反引号和代码围栏内停笔；代码围栏外的后续普通文本仍可补全。不是代码补全器或完整 Markdown 解析器。
- 保留已有换行、段落、缩进和列表标记；列表续接核对编号递增和样式。拒绝新建无关标题/代码包装、未闭合原子内容、连续逗号及藏在列表后的回应。
- 本地最多 192 token，候选资源上限 240 个 UTF-16 单位；不是目标字数。不按长度硬切片，`finish_reason=length` 直接不显示。常规片段下限仍为 10，4–9 字且带句末标点的结尾可自然收句，不为凑字数扩写。
- 请求中附上原文逐字提取的最近分句、明确限定范围及否定操作，提醒模型不要把禁止修改的对象变成新任务。没有生成式摘要，不补猜测的意图。

未解决：词汇/分句检查不是语义等价判定；同义复述、潜在范围扩展和模型判断错误仍可能通过。新增短结尾规则只判断标点，不证明语法或语义完整。不能宣称全部输出符合用户的精准续写要求。

# 0.3.9 飞书文档表格续写修复

日期：2026-09-20。用户提供订单样式策划案表格截图，反馈单元格中不出现提示。本轮保留此前未提交的0.3.8文档模式修改，只修复活动编辑器识别；未提交或推送。

## 根因与修复

- 截图及同一文档的只读结构确认：表格内部有独立 `zone-container text-editor` 段落，活动段落保留 `text-editor-focused`，系统焦点仍可能落在外层文档根。
- 首轮仅加入不含正文的扫描诊断，并备份安装诊断版。原问题文档聚焦表格段落后报 `feishu_editor_stage=ambiguous nodes=866 durationMs=43`。不是此次采样的超时或模型无候选。
- 原生 AX 表格会通过不同结构路径暴露同一控件；指向同一远端 AX 元素的包装对象可以地址不同。旧实现按指针去重，重复经过同一个活动段落时误判成两个不同输入目标。
- 新实现仅对真正的 AX 元素使用 `CFHash/CFEqual` 身份去重，普通合成夹具节点仍按指针识别。共享单元格引用跳过重复扫描；当前祖先路径中的环仍拒绝。两个真正不同的活动段落、未知根、超限/超时仍拒绝，1500节点、32层、0.2秒预算保持。
- 诊断只记录阶段、节点数、重复引用数及耗时，不记录正文或节点标识。提示词仍为 `.19`；模型、用户设置、读取权限、上下文范围、插入方式没有改变。资源版本更新为0.3.9/build12。

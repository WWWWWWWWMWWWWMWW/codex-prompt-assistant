# 0.3.12：文档接受后的连续续写阶段

2026-09-22。用户要求解决飞书文档服务返回空内容的问题。本轮修复已确认的阶段传递缺口并安装；没有证据证明所有空结果均为异常，亦未完成真实文档连续 Tab 显示验收。没有提交或推送。

## 证据与改动

0.3.11 的飞书文档样本在接受回读匹配后约 281ms 发出下一轮，服务返回 HTTP 200/empty_content；同一窗口另一次为 filtered。请求已完成，没有无限等待。源码在主程序和客户端均排除 documentContinuation，接受后的文档仍按普通首轮发送。

新增文档生命周期用例在修改前第二、第三轮阶段断言失败；修改后通过。当前把文档末尾的已匹配接受阶段传递给远程协议，保留输入/字段/光标/上下文身份绑定与编辑/边界清除。请求缓存、在途合并隔离普通/接受阶段；文档使用独立正文提示，不借用聊天提问模板。中间插入、本地模型和普通首轮保持原模板，空结果不盲重试、不填固定句子、不自动发送。

文档接受阶段允许同主题自然说明，同时要求业务规则有原文依据，完整封闭范围或缺参数仍停笔。仅补齐阶段传递，不声称知道服务内部为何停笔；用户当次空内容是否属于过早停笔，因未读取或保存真实草稿而未复现。

## 合成语义实验

四批旧/新配对共 48 请求，最终生产客户端另外 9 请求，均使用固定合成文本和已有配置，无真实文档、正文或 Key 记录。

- 第一版：开放说明两者都能续写；完整积分来源仍新增数值/发放条件，未采用该版。
- 最终版：明确一般说明与业务规则的区别，封闭积分来源和仅补发未领奖励样例返回空；缺参数样例保持空。
- 已接受较长说明的配对：多数两者都有输出，一条已完整的准确性说明两者都空。因此**本次配对未证明整体空结果率下降**，不能把阶段修复或新增输出能力写成已证实的语义收益。
- 残余反例：仅已知普通订单使用常驻池时，两版都推断活动订单使用活动池。该规则缺少依据，不能算正确续写；未以该例的非空输出作为通过证据。提示词约束仍不等于业务规则绝不编造。
- 最终生产多轮：响应体验说明 3/3、AI材料核对说明 3/3 均生成同主题正文；三条封闭/缺参数边界均空。9 次 HTTP 200、1828–4092ms。这里只证明这些合成案例的真实客户端多轮，不证明空结果比例、整体质量或速度改善。

# 0.3.4：光标中间插入与飞书文本坐标

日期：2026-09-17。来源为桌面原始工作区，保留既有 dirty 修改，无提交或外部发布。提示词独立版本 `2026-09-17.18`，产品版本 0.3.4 / build 7。

## 已确认的问题

1. 0.3.3 的公共请求/显示校验要求光标等于全文长度，因此飞书文档中间光标不能生成。此前前台采样捕捉到正文长度 1366、选区长度 0、光标 700/681/682；不是只读取到了末尾空白。
2. 只读复核目标文档：`AXValue` 长度 1366，`AXSelectedTextRange` 光标 627；与该光标一致的 `AXStringForRange` 完整序列长度 928。当前可见段落在展示文本中的起点 978，在范围文本中起点 615。表格/图片等展示投影使两者无法直接按同一索引切分，单纯跳过换行也不成立。
3. 聊天“按住 fn 说话 / 发送给…”是占位内容，不能用其样本替代文档证据。

## 实现

- 在线请求允许正文中间的空选区光标；模型接收分开的 `before_cursor` / `after_cursor`，只生成两者之间的新增部分。短衔接词允许发布，输出仍经过原有不回答、不改意等检查。
- 前后文均先脱敏；后文仅发送前 2000 个 UTF-16 单元，不截断组合字符。前文沿用最多 2000 单元的现有限制；不宣称任意长文档任何位置都支持。
- 完整后文加入缓存/请求身份，输出检查与后文重叠；中间插入不显示尚未完成最终校验的流式片段。接收回包与 Tab 前均重新核对全文、光标、焦点、策略和上下文。
- Tab 沿用只投递新增文字的方式，预期读回为“前文＋新增部分＋后文”，不替换文档、不自动发送。
- 飞书改读光标坐标对应的范围文本：先证明上界外不可读，再有界查找逻辑全文长度，复读全文并核对光标前缀；随后重新核对原 AXValue、焦点身份和原选区。接口错误/不一致时拒绝，不能猜位置。AXValue 投影超过 65536 单元暂不读取。
- 飞书聊天占位内容保持为空输入；没有可用光标矩形时沿用输入区域提示条。
- 设置仍只有在线开关、Key、多选范围。十项目录无 App Store，Codex / WorkBuddy 安装默认选择并保留明确取消。

## 验证与证据

- `make test remote-completion-test`：完整应用、生命周期、设置、策略、键盘、AX 读取、协议、客户端、凭据等通过。最终日志见 [offline-regression.log](../evaluation/results/middle-insertion-2026-09-17/offline-regression.log)。
- 合成中间插入验证 `请说明|的原因。后续段落保持原样。` → 插入 `接口超时`；完整后文保留。覆盖回包前后文变动、Tab 前后文变动、Tab 前光标移动，均拒绝旧候选。另覆盖后文重复/标点、短插入、缓存隔离、两侧脱敏、预算及 Unicode 边界。
- 飞书读取算法覆盖展示/逻辑文本长度不同、末尾光标、错误上界、读取期间变更、前缀不一致等离线用例。真实只读探针运行相同范围读取函数得到逻辑长度 928 / 去包装后 927 / 光标 627；13 次范围读取约 1.27ms，正文复读保持、请求门槛允许。证据 [feishu-range-read.json](../evaluation/results/middle-insertion-2026-09-17/feishu-range-read.json)。这是单次读取样本，不是生产性能保证。
- 该探针采样时系统前台报告 false；它证明目标文档的范围读取，不证明新版前台触发、浮层或实体 Tab。后续完整 reader 探针遇到用户已切回聊天的 AXWebArea，不把它判成正文读取失败或通过。没有输入、改写或发送用户文档/聊天。
- 回归最初发现旧请求入口被新重载绕过，导致质量工具计数误判；已保留末尾请求原入口，完整回归重跑通过。曾尝试展示字符串换行映射，真实文档不成立，最终改为范围全文读取；未交付猜测映射。
- 提示词 .18 的独立离线验证通过；没有使用真实 Key 进行新的联网语义质量评测，不宣称模型输出质量已全面验证。
- `make app` 构建/严格验签通过；安装器隔离自测 26 项通过。DMG 只读挂载后核对安装器/载荷签名、完整清单、精确 0.3.3 升级基线及 222 文件源码快照全部通过，测试卷已卸载。

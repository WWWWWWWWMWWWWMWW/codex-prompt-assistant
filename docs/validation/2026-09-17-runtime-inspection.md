2026-09-17。继续 C23 服务适配准备，完成可复用的只读检查部分；未启动更新事务。

## 实现与依据

新增 `Tools/Release/helper_runtime.py`，将此前临时核查中的运行身份/参数检查落实为有测试的 CLI。调用系统只读 `launchctl print`、`ps`、`lsof` 及严格验签，核对：

1. 当前 GUI 用户固定助手 label 处于 running，PID 唯一，程序和独立参数与约定配置匹配。
2. 正在加载的配置路径为目标用户内的普通文件，最多读 64 KiB，禁止路径符号链接；磁盘配置与已验证启动约定一致。
3. 实际助手命令行精确包含约定的两个参数，包/运行声明同时成立；相似参数、额外参数或只有磁盘配置成立均不通过。
4. 三进程 PID 各不相同，模型服务 PID 与指定值一致，助手执行路径与安装目标一致，lsof 映射的路径/设备/inode 与已安装可执行文件一致。
5. 前后运行与配置快照一致，包严格验签和 SHA256/树摘要核对通过。

报告不输出原始配置、命令行或日志，只输出核对后的身份、散列和限定结果。普通命令失败保持未知，不把失败解释为助手已停止。

**健康边界：**旧启动日志只能证明历史时刻启动过，进程存在也不证明主线程或输入监听现在有响应。本工具始终返回 `healthVerified=false` 和 `automaticUpdateReady=false`，不消费日志来制造实时健康结论。

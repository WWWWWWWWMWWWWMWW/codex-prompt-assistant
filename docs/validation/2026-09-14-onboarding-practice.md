# 简短新手练习验收

日期：2026-09-14。已实现、构建并安装；仍属个人 Alpha。本轮延续用户“继续”授权，只增加可选教学练习。

## 已确认的交付

入口为“设置 → 高级与帮助 → 练习接受与忽略”。打开后焦点位于固定示例：Tab 接受第一段灰字，再按 Esc 忽略第二段；两步完成后显示“已学会操作。回到真实输入框试试吧。”。可随时点“跳过练习”，也可重新练习和再次打开。没有新增首页开关、常驻页面、首次启动强制弹窗或持久化教程状态。

实现仅位于 `SettingsWindowController.m`，由局部只读 NSTextView 接收练习按键。它不接入 provider、历史、偏好写入、宿主插入和全局键盘监听；运行所有权继续保留在原委托。只有练习区聚焦且练习未完成时处理不带修饰键的 Tab/Esc，重复按键不推进，Shift-Tab 保留原生行为。关闭释放回调，重开从第一步开始。此练习不证明辅助功能、模型连接或生产候选可用。

## 必要设置与操作路径

| 项目 | 处理及依据 |
| --- | --- |
| 本机补全、在线补全 | 首页保留两个独立开关；分别控制本机计算与联网选择，不能合并后擅自切换用户意图 |
| 权限 | 仅缺失时首页给入口；已有授权不要求重复操作 |
| 在线 Key/模型 | 已配置不重复填写；首次启用未配置时直接进入配置，成功保存才启用；沿用上一包验证 |
| 使用范围 | 日常沿用推荐；当前应用/站点可从菜单栏直接关闭，复杂例外保留在次级入口 |
| 历史导入/表达使用 | 保持可选，既有独立控制保留；不作为开始补全或完成练习的前置条件 |
| 教程 | 只提供两步可重开的练习；不要求填写偏好、导入历史或完成多页向导 |

因此日常使用仍是“在允许的输入框写字 → 有灰字时 Tab 接受或 Esc 忽略”。打开设置和练习均不是每次补全的前置步骤。

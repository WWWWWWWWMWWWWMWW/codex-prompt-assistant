# 0.3.0 在线精简版验收

## 已确认的实现

设置单页仅三组：在线续写、API Key、使用范围（独立复选框）。无本地/表达/历史/模型/高级/练习设置页或菜单入口。缺辅助功能权限时的授权按钮属于首次运行必需操作；保存反馈与错误状态在原页显示。

首次升级范围为空；以独立偏好保存，不自动继承旧版隐式权限。应用精确 bundle ID 匹配，网站精确主机匹配；多选取并集，只对当前前台输入生效，不合并跨应用正文。Codex/WorkBuddy 维持已有关联任务上下文，其他范围只用当前输入。浏览器仅探测决定策略必需的元信息，未知主机/未选站点/敏感输入不读取正文。取消范围使 ruleVersion 变化并取消请求、隐藏候选，迟到接受回调不能插入。关闭在线续写也清除任务上下文选择。

在线版强制禁用本地模型与表达库查找，停止自动历史扫描；不改旧本地开关偏好，不重启 Codex 或常驻模型。未改提示词、默认模型或质量过滤。

安装器必填 Key，明确固定服务 sapi-ai.hortorgames.com；使用既有 RemoteAPIKeyFileStore 加密保存（0600），偏好只保存配置标记，没有 Key 明文。空白和包含内部空白的 Key 拒绝。只校验格式/保存，不宣称认证或额度已验证。保存失败明确报错，可重试；应用文件安装与 Key 保存不是同一个原子事务，Key 失败时应用可能已安装，不会自动打开。

旧助手运行时不安装，也不自动终止进程。仅允许已交付 clean 64d9475 的精确 0.2.0 包升级，或同一新版重装；未知/被改动旧包拒绝。升级后原包保留在 ~/Applications/.cpa-upgrade-backup-UUID/；不修改 LaunchAgent。新 Key 替换旧 Key，应用回退不回退 Key。

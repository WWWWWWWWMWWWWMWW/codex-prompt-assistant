# 验收记录模板（复制后填写）

此文件是模板，不是一次通过记录。未执行项保留“未验证”，失败不改成跳过。仅使用合成文本或夹具 ID，不粘贴用户正文、密钥、完整原始日志或完整进程参数。

## 范围与对象

- 日期/时间、任务范围、明确排除项：待填写。
- 代码实现提交 / 测试提交：待填写；文档提交与行为提交可不同。
- 构建 GitCommit / dirty / 产品版本 / 提示词版本及源码指纹：待填写。
- 构建包可执行哈希 / 磁盘安装包身份与哈希：待填写；旧包可标 legacy unknown。
- 运行助手 PID / 启动时间 / 对应启动日志身份：待填写；未知不能由磁盘反推。
- 操作前后 Codex / 模型 PID 与启动时间：涉及运行操作时必填，否则写本轮未操作。
- 宿主应用版本、窗口/控件、输入来源、规则/搜索/远程位：实机时填写。

## 断言与证据矩阵

| 断言 ID / 契约 | 方法与对象 | 证据层 | 命令退出码或观察 | 结果 | 限制 / 下一步 |
| --- | --- | --- | --- | --- | --- |
| 待填写 | 具体测试名/夹具步骤，不只写“测试通过” | 静态 / 离线 / 构建 / 磁盘包 / 运行 / 实机 / 语义 | 未执行 | 未验证 | 待填写 |

静态源码证明存在机制或缺口，不能单独证明事件发生；离线桩不证明宿主支持；codesign 不证明运行版本；无候选不证明零读取；语义质量与候选覆盖率分别报告。

## 测试资源与恢复

- 测试临时目录/窗口/服务是否由本次创建，是否触及共享日志、钥匙串或用户配置：待填写。
- 原完整规则与存在性、阳性对照、前后输入长度、候选/插入差量：按用例填写。
- 恢复/清理完成依据，失败或失焦时保留了什么：待填写。不得因为归属不明而扩大删除范围。

## 结论

- 已验证：待填写。
- 失败：待填写或明确无；描述证据和影响。
- 未验证/跳过及原因：待填写或明确无。
- 是否允许下一动作、依据哪个门禁、仍有哪些阻断：待填写。

最终提交产生的新构建身份在交付时另行核对；本记录固定已测对象，不反复把自身最终 SHA 写回自身制造 dirty 循环。

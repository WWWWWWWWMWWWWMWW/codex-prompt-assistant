# 设置简化：双开关首页

2026-09-14。用户反馈五页设置复杂，要求仅保留必要设置并缩短操作路径；经核查方案后明确要求继续实施。本轮在原工作区现有实现上修改，未覆盖既有改动、提交或推送。

## 已完成

首页从五页侧栏改为一个 640 × 440 的窗口，正常状态只显示：

- 本机补全、在线补全两个即时开关。
- 使用范围、高级与帮助两个次级入口。
- “Tab 接受 · Esc 忽略，不会自动发送”的简短说明。

暂停、缺权限、来源全关、在线未配置或最近一次已启用来源请求失败时，首页显示对应提示；可处理的情况附继续、设置权限、配置或详情按钮。不把开关开启称作服务健康，不把正常无候选显示为故障。空提示区域折叠，首页正常状态无需滚动。

| 用户操作 | 精简后的路径 | 保留的功能边界 |
| --- | --- | --- |
| 暂停所有提示 | 菜单栏 → 暂停提示 | 保留来源选择及手动历史暂停；首页出现继续入口 |
| 关闭当前范围 | 菜单栏 → 在此应用/站点关闭提示 | 使用菜单打开时冻结的对象和 PID 校验，保留原联网/搜索权限 |
| 启用当前范围 | 菜单栏 → 在此应用/站点启用提示 | 仅允许普通输入；不会顺带授予联网权限。推荐默认关闭的浏览器/终端显示启用 |
| 设置应用例外 | 首页 → 使用范围 | 仍有三种规则模式及独立联网授权；搜索例外折叠在更多规则选项中 |
| 首次开启在线来源 | 开关 → 配置 → 保存后启用 | 取消或保存失败不新增联网启用；已开启但未配置的旧状态仍原样显示，提供配置入口 |
| 修改服务配置 | 高级与帮助 → 在线服务配置 | 草稿跨页保留，失败可重试，放弃/关闭清理输入；不回显密钥 |
| 管理历史 | 高级与帮助 → 历史数据 | 导入与表达检索分别控制；不影响当前输入/当前任务上下文的既有策略 |
| 排障 | 高级与帮助 | 权限、重连、请求结果、构建身份继续可达，首页不再堆放技术信息 |

“关闭/启用此范围”是持久规则编辑，因此文案没有将其称为临时暂停。重新启用设为“允许普通输入框”，恢复推荐仍可在使用范围或高级规则中选择。敏感字段、永久保护应用、未知浏览器主机和插入前焦点校验保持原有保护。

实现：[设置窗口](../../Sources/CodexPromptAssistantPOC/SettingsWindowController.m)、[菜单及运行操作](../../Sources/CodexPromptAssistantPOC/main.m)。本轮 main 改动限于菜单排列、快捷规则入口和默认类判定，未改提示词、模型、上下文、生成或插入算法；没有重置任何用户配置。

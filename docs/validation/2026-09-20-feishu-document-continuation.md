# 0.3.8 飞书文档正文续写

日期：2026-09-20。用户要求飞书文档提示直接续写文档和策划案，不再补成问题。本轮本地修改、备份安装，未提交或推送。

## 已确认的原因与修改

原通用模板明确要求“Continue composing that question”“Preserve AI-prompt language”和补充核查、比较、依据要求。飞书正文也经过这一模板，存在把策划正文补成对 AI 的请求的直接诱因。

- 仅飞书客户端或已授权飞书文档浏览器页内、具有 `zone-container` 与 `text-editor` 元数据的 `AXTextArea` 使用文档模式；普通聊天、其他应用、未知站点和非正文角色不因此切换。模式判断不读取正文，不改变原策略授权。
- 文档模板直接续写当前半句、段落和条目，保留规则中的条件、行为、结果及作者语气；不得改成核查/说明请求、擅自增加玩法、奖励、数值或未确认事实。重试及已验证 Qwen 前缀模板使用对应文档约束；原聊天模板保持。
- 模式同步冻结到请求与快照，并参与在途请求、缓存、显示和接受签名；文档路径不走聊天选项/范围的字面续写捷径。双开时本地仅字面补齐的原调度限制保持，设置未切换。
- 产品 `0.3.8/build11`，提示词 `2026-09-20.19`。只有模式布尔值进入诊断，不记录输入正文。

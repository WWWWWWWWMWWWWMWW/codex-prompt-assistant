# 2026-09-10 保留承接链的上下文优化验证

用户授权继续优化，依照 [实验设计](../plans/2026-09-10-user-turn-context-design.md) 完成工具专用消息选择器、两轮 64 次对照及逐条评阅，详细输出和分母见 [实验记录](../evaluation/results/user-turn-context-2026-09-10/README.md)。没有改变生产请求、过滤或上下文预算，不安装、不重载、不提交。

## 结果

本地严格可用 8/16→10/16，两个否定现象偏移被消除，简短确认承接对象保持；仍有 6/16 次对象/范围偏移。远程计数 5/16→7/16，但新增严格正确没有发生在实际裁剪材料的用例，不能称为方案收益。两路均未达预设门槛，因此没有接入生产。

这一轮把“删去最近用户后的助手解释”和“只留最近一条用户消息”区分开了，保留确认链的局部改进有样本证据；它不解决第二项等指代和无依据范围扩展。只看消息位置与引用词不能建立可靠事实/采纳关系。下一方案需要显式表达来源和引用关系，并检测材料缺失，不能默认把消息前缀等同于已确认事实。

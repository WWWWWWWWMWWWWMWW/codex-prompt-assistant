# 作者侧深化与独立调度 .16

用户明确要求取消本地串行等待、允许更长续写、将 AI 固定为站在作者一侧深化输入。此前“等待确认深化边界”已被本次确认取代。

## 实现与证据

- 删除 `startDelayedRemoteModelSuggestions:` 对本地任务的 250 ms 轮询等待。保持独立防抖、同输入/上下文/策略/暂停验证和首个合格候选固定。真实生产委托回放先复现 5 个失败，修复后 C1 为 0 failures；本地挂起、远端先显示和迟到本地均覆盖。
- v1/v2 共 160 次真实合成客户端对照，均保留失败。两版本地作者扩写都不能保持原意；未采用失败模板。远程改为固定作者身份、直接可插入的相关要求，允许连贯展开；简单缺词仍补词，明确范围不扩展。不增加模型、令牌预算、二次语义审核或关键词黑名单。
- 最终采用按能力分工：双开且策略允许远程时，本地仅使用既有严格字面选项/范围路径；开放生成交给远程。`literalContinuationsOnly` 在请求入口取快照，纳入同请求合并身份，在缓存/模型发现/HTTP 前执行。旧模型缓存或运行中任务不能冒充字面结果。远程故障不自动退回本地语义扩写。
- 本地开关关闭仍完全关闭；仅本地或当前应用只准本地时保留原有本地生成契约，其通用语义缺口未解决。此策略不写偏好、不重启模型。详情见[设计](../plans/2026-09-10-author-deepening-design.md)。

## 最终验证

[完整证据](../evaluation/results/author-deepening-2026-09-10/README.md)，共 232 次客户端尝试；原文均为合成夹具，评阅非独立盲评。

最终 72 次组合回归中，本地 4 次字面成功且 0 模型请求；远程 24 次深化任务中 23 次可显示、1 次超时，另短补词 2/2、字面路径 4/4、保守停止 6/6。逐条拼接未见直接答题或明确范围改写。不把本地不输出计为其理解能力提升。

共同四类远程可用候选字数中位由基线 28 到最终 36；其中范围限制仍短，排查要求更完整。远程模型请求耗时中位基线 2621 ms、最终 2525 ms；仅描述受测样本，不能声称模型或实机因此稳定更快。调度已经消除本地前置等待，旧配对实验到达时延不能直接当本轮 UI 验收。

`make remote-completion-test`、`make test` 最终通过，C1/质量工具均 0 failures；包含请求模式/旧缓存/同请求合并/暂停/应用策略与迟到候选回放。公共入口禁网、私有诊断和合成凭据。构建及部署身份另附安装结果，不把源码测试等同实机插入。

## 失败和修正均保留

1. 新生命周期测试首次误用不存在的测试属性，编译失败；改为真实浮层替身字段后，旧调度复现 5 个预期失败，修复通过。
2. v2 本地新增少样本改变 ChatML 示例数量，旧角色数断言失败；该本地模板本就语义不合格，最终恢复原本地模板和示例。
3. 字面模式先复现旧缓存穿透；修复后，原有异步合并测试的合法请求污染后续零 HTTP 计数，移到所有计数断言之后，保留原测试目标。
4. 模式合并测试最初检查了任务内部 phase，而终态 phase 在结果对象；改为等待结果再断言，最终通过。
5. 旧实验工具假定所有模板都有旧重复规则；远程作者模板已经收窄至当前草稿，该旧单变量实验现在应为无变化，测试分别验证旧/新模板语义，最终应用回归通过。
6. 真实请求共 3 次超时（基线、v2、最终各 1），v2 另有一次正确短候选被现有最小长度门拒绝；均保留。最终短控制通过，不因此声称所有短句都已解决。

## 验收限制与下一步

完整问句/完整限制句暂保留停笔，这是保守实现限制；不能称所有输入都已可深化。远程仍可能超时或产生未覆盖的语义错误；仅本地生成仍有已知原意偏移。更长本身不等于更好。

实机浮层与 Tab/Esc 本轮未复测：此前 CUA 和助手所见前台归属不一致，本包未改焦点路径，不用部署自测替代实机验收。下一步优先验证实际候选来源、从停笔到显示的时延；再独立评估完整问题后的作者侧追加要求和远端超时。禁止为了覆盖率自动恢复失败的本地扩写。

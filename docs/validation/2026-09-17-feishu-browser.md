# 0.3.5 飞书网页版支持

日期：2026-09-17。原始桌面工作区，保留 dirty 修改；无提交、推送或公开发布。产品 0.3.5 / build 8，提示词保持 .18，未改变模型或生成预算。

## 已实现

- “飞书”显示为“飞书（含网页版）”，一个选项同时授权客户端和网页，取消同时停止两者；设置仍仅在线续写、Key、多选范围，十项目录无 App Store。
- 浏览器只有在飞书已勾选时才检查当前焦点元数据。最近的 AXWebArea 提供页面归属；只允许 HTTPS、单层租户 `*.feishu.cn`、`/docx/<id>`、`/docs/<id>`、`/wiki/<id>` 路由。拒绝其他网站、域名仿冒、登录/未知路径、地址栏、搜索和敏感输入；不读取其他标签页正文。
- 飞书网页复用客户端的光标范围文本读取和中间插入；光标后文保持，范围/正文/光标不一致时停止。页面 URL 加入内存中的字段标识，外部只使用随机身份 token；读取正文前后重新核对主机和字段，切换文档或网页令旧候选失效。
- Codex/WorkBuddy 默认勾选及已有勾选保留；升级不增加其他设置，不修改在线开关。

2. 中间插入生命周期回放覆盖客户端与 Chrome；接受保留后文、回包期间后文变化、Tab 前正文/光标变化、文档身份/主机变化均按预期处理。主程序集成覆盖飞书取消时撤销浏览器接受票据。

# 2026-09-09 任务绑定与草稿修订分离

## 根因与改动

输入事件回调直接清空 codexIDIdentifier，input_changed 取消路径再次清空；ensureCodexID 按完整输入签名缓存。
因此同一任务中改字反复发送 Cmd+Option+L、失效上下文并取消生成。ID 能解析不等于连续打字体验合格。

本轮新增 conversationSelectionIdentity：实时核验选中侧栏节点，绑定 AX 元素、所在窗口、Chrome 节点号，以及标题/AXIdentifier/URL 元数据的变化。
它是内存中的界面选中身份，不是线程 UUID；第一次仍使用已有链接事务获取 UUID，随后按进程、控件和选中节点复用。
缓存标题的宽限期、浮窗关闭按钮、无选中节点或读取失败不构成身份依据；这些场景清除历史绑定，使用当前草稿，不反复探测快捷键。
普通输入事件只取消尚未完成的 ID 事务，已完成绑定保持；input_changed 仍取消过期候选与生成请求，但不清空任务身份。

选中节点进入候选 HMAC 签名；同标题节点切换、窗口/进程/控件变化和身份缺失会撤销旧上下文。
鼠标点击及非普通编辑的 Command/Control 快捷键额外撤销任务绑定与候选代次，防止导航复用 AX 节点。
普通打字及 Cmd+A/C/V/X/Z 不作为导航；自身 ID 探测标记不会触发自取消。
Tab 接受继续重新核对实际 UUID 和新鲜输入，不降低插入保护。首次选中任务、导航之后和接受时仍可能触发一次复制快捷键，不宣称完全无主动探测。

## 未验证与限制

安装轮没有操作真实草稿，未做实机持续输入、切换与 Tab 验收。随后用户反馈“打字已无闪动，任务切换时响应平稳，未见提示框异常出现”，这三项已取得用户体验证据；不等于正常候选显示和 Tab 插入已通过。后续独立合成检查见 [回读记录](2026-09-09-insertion-readback.md)。当前 Codex 构建是否在所有侧栏布局持续提供明确选中节点仍待运行验证；缺失时只使用草稿，可能减少依赖历史的提示。
仍不能证明任意外部程序导航并恰好复用所有 AX 元数据时都能提前发现；Tab 的实际 ID 核对保留最后一道任务归属检查。
无提示还可能来自输入期间取消、模型留空、边界拒绝或质量门，本修复不能保证每次输入都有候选。

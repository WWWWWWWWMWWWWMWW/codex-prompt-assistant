## 新用户路径核查与发布依赖

| 顺序 | 当前源码证据 | 后续工作与放行依据 |
| --- | --- | --- |
| 1. 先确定新用户实际可用的补全来源 | `RemoteCompletionSettings.m` 固定在线服务地址；本机启动只尝试加载已有模型服务，不安装运行时或权重 | **建议：**首先只交付已具备可用服务的一条完整路径，另一来源保持可选。**待确认：**外部试用者的服务使用权、凭据/费用承担和模型供给；这些会改变首次配置与安装范围，不默认向外提供当前服务 |
| 2. 再消除安装前提并验证恢复 | `Makefile` 的 `local-model-service-install/start` 及模型 plist 含固定用户名路径；运行时/缓存均在个人目录。助手安装入口也仍依赖构建工具 | **已确认缺口：**当前不是普通用户拖入即用安装包。路径生成必须跟随目标用户，缺运行时/权重时应给可执行说明；选定交付方式后再做干净用户与无开发工具环境验证。旧包恢复必须使用已保存的旧包，不能调用会重装当前 build 的 `service-start` |
| 3. 最后验证真正的新手闭环 | 首页权限入口只调用现有系统授权请求，状态每秒刷新；已配置本机的 TextEdit Tab/Esc 证据不覆盖新用户 TCC 状态 | **未验证：**干净 macOS 用户实际拒绝授权、返回授权后恢复、新装/升级/失败回退和声明的宿主矩阵。安装与服务路径稳定后，在同一候选包完成这些验证，避免换签名或改安装身份后旧证据失效 |

**发布划分不变：**本轮属于 S1 个人试用中的操作路径修正；S2 小范围新手试用必须同时满足可获得的服务、可重复的安装/授权/恢复及所声明场景的质量兼容门槛。S3 公开测试再叠加公开分发身份、许可/隐私说明、名称与支持资料。界面简化减少操作步骤，不删除发布依赖。

本轮没有注入真实凭据失败、撤销本机系统权限或创建新的 macOS 用户；没有重新验证新版的实体 Tab/Esc、通用回滚、模型质量/性能。凭据错误路径为隔离回归证据，恢复操作为实际窗口与运行日志证据。没有提交、推送或对外发布；持续任务仍保持暂停。

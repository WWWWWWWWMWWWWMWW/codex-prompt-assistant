# ADR-0001：聊天来源与同步边界

## 状态

适用范围补记（2026-09-08）：背景中的“全部聊天”不是当前实时读取承诺；有限实时上下文与离线索引边界见 [ADR-0007](0007-m0-current-baseline.md)。

接受

## 背景

工具需要使用全部 Codex 与 ChatGPT 聊天，但当前桌面应用没有稳定公开个人 ChatGPT 历史接口，也未稳定暴露聊天正文和当前任务 ID。

## 决策

- Codex 根用户任务采用本地只读扫描与增量监听。
- 普通 ChatGPT 历史采用官方导出包导入和后续重复导入补齐。
- ChatGPT 桌面实时采集只作为后续实验能力。
- 不调用私有接口、不读取登录令牌、不使用 OCR 静默冒充完整采集。

## 后果

### 正面

- 数据完整性和隐私边界可验证。
- Codex 升级或局部格式变化时可以降级和重建。

### 负面

- 普通 ChatGPT 后续补齐仍需要重新导入。
- 无法承诺所有入口实时同步。

## 替代方案

- 私有接口：因凭证、账号和兼容风险拒绝。
- 屏幕 OCR：因遗漏和错字风险，只保留为实验，不进入正式承诺。

# ADR-0002：本地学习与远程补全

## 状态

早期阶段接受；生成方式部分已被后续实现替代。

2026-09-08 注：以下原决策保留作为历史。生成职责的后继记录见 [ADR-0007](0007-m0-current-baseline.md)。当前已使用本地模型续写；本机运行状态与证据见 [当前架构](../architecture.md) 和 [状态页](../status.md)。本地原始数据与派生表达分离原则继续适用。

## 背景

表达库需要自动成长，但完整聊天包含大量隐私、工具输出、代码和敏感凭证，不能把全部历史反复上传给远程模型。

## 决策

- 原始聊天、表达抽取、去重、权重学习和检索均在本地完成。
- 本地学习使用规则和统计，不引入本地大模型。阶段 2 的简化首版按 ADR-0005 使用加密表达＋运行时内存前缀检索；FTS5 和字符相似度留到真实失败案例证明需要时再评估。
- 远程接口只负责最终续写，输入限制为当前文本、已确认最近对话和少量脱敏检索结果。
- 原始层与派生表达层分离，表达库可删除、回滚和重建。

## 后果

### 正面

- 安装较轻，行为可解释，历史不整库外发。
- 算法升级不破坏原始资料。

### 负面

- 第一版对复杂语义近义表达的召回弱于向量模型。

## 替代方案

- 轻量本地模型：留到真实失败案例证明需要时再加入。
- 远程批量抽取：因隐私、成本和接口依赖拒绝作为默认方案。

# ADR-0003：Codex 实时建议接入方式

## 状态

已接受（阶段 0 于 2026-08-20 实机通过）

## 背景

Codex 没有公开的输入框扩展接口。目标是实现接近代码补全的灰字体验，同时不能修改应用包或影响中文输入法。

## 决策

- 优先验证 Accessibility 读取输入框、定位光标和安全插入文本。
- 使用不抢焦点的 macOS 浮层显示建议。
- 只有建议有效且不处于输入法组词状态时才处理 `Tab`；`Esc` 只关闭当前建议。
- Codex 的 `AXBoundsForRange` 返回零尺寸假坐标，因此采用输入框上方、不抢焦点的候选条；不承诺原生光标内 Ghost Text。
- 中文输入源下通过本地组词状态保护 Tab/Esc，并将输入法常驻菜单栏状态项与真实候选面板区分。

## 后果

### 正面

- 不修改 Codex，不破坏签名，可独立升级和停用。

### 负面

- 无法保证达到编辑器原生 Ghost Text 的换行和排版精度。
- Codex 升级后需要重新运行兼容性探测。
- 阶段 0 使用临时签名；正式交付必须使用稳定的 Apple 开发者签名，避免辅助功能授权失效。

## 替代方案

- 自定义输入法：与用户现有中文输入法冲突，拒绝。
- 注入或修改 Codex：升级、安全和签名风险过高，拒绝。

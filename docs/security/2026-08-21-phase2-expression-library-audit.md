## 安全边界

- 原始消息和表达正文使用现有 Encrypt-then-MAC 信封加密；数据库文件权限为 `0600`。
- 表达摘要是域分离的 keyed HMAC，只用于去重和墓碑，不用于展示或搜索。
- 表达快照整批事务替换；来源关系或构建失败时保留上一个完整快照和内存索引。
- 输入框正文只在运行时快照和匹配协调器中短暂存在；摘要、诊断、日志和输入签名只包含长度、选区、计数和耗时。
- 自动路径没有固定建议兜底；无匹配时不显示，Tab 只消费当前后缀一次，Esc 立即清除。

## 未验证与保留风险

- 真实历史尚未导入；本次只证明合成数据下的正确性、规模和隐私边界。
- 临时签名应用的菜单栏实际视觉、首次扫描确认和真实 Codex 输入框端到端插入仍需人工现场验证。
- SQLite 元数据不是整库加密；时间、角色、计数和随机外部 ID 仍可见。
- 49.2MB（约 46.9MiB）的测得增量接近 50MiB 门槛；第一版通过，但未来增加模板、语义索引或更多常驻字段前必须重新测量。

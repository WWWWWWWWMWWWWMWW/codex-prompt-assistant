# Phase 3 远程智能补全安全审计

日期：2026-08-21

## 范围

- 固定服务：`https://sapi-ai.hortorgames.com/v1`
- 本地无表达匹配时的远程补全请求
- API Key 存储、请求字段、敏感信息脱敏、日志、取消和回包校验
- `gpt-5.6-sol` 的兼容验证与 `4.1-nano` 的低延迟验证

## 数据边界

- 首版只发送光标前的当前输入，不发送本地历史消息、表达库、线程 ID、工作目录或本地数据库内容。
- 当前输入发送前再次经过 8 类敏感信息脱敏；请求体只允许 `model`、两条 `messages` 和 `stream=false`。
- 不发送 `temperature`、`max_tokens` 或 `max_completion_tokens`，避免聚合服务不同 5.6 后端的参数兼容差异。
- 回包只取第一条文本后缀，归一为单行并在本地截到 160 个字符；输入变化、Esc 或新请求会取消／丢弃旧回包。

## 凭证

- API Key 仅存入 macOS Keychain：service `local.codex.prompt-assistant.remote`，account `api-key-v2`。
- 模型名存入 UserDefaults，当前内联补全模型为 `4.1-nano`；UserDefaults、SQLite、源码和诊断日志不保存 Key。
- “已配置”状态使用不含秘密的 UserDefaults 布尔标记，应用启动不会为了显示菜单状态读取 Key；实际 Keychain 查询禁止认证 UI，失败时静默停用远程建议，不允许系统弹窗抢焦点。
- 本地历史正文仍使用 AES-256-CBC＋HMAC 加密；历史库主密钥不再走 Keychain，而是保存在应用专属目录下的 `master-key-v3.bin`，通过 `O_NOFOLLOW`、所有者／硬链接检查和 `0600` 权限读取，避免临时签名导致系统授权弹窗。
- 用户本轮确认保存的 Key 已经出现在聊天中，属于已暴露凭证。当前仅用于首版联调，正式使用前必须在服务端轮换并通过设置页替换。

## 剩余风险

- 脱敏是启发式防线，不能保证识别所有业务秘密；第一版不上传历史可以显著缩小暴露面，但不能把任意当前输入视为无敏感信息。
- Key 已在聊天中暴露，Keychain 只能保护本机落盘，不能撤销已发生的泄露。
- Codex 错报光标为零且不给坐标时使用句尾降级；用户真的在开头／中间编辑时可能得到位置不合适的建议。
- 当前快速模型典型延迟约 0.9～1.1 秒；超过 6 秒会超时并静默不显示，首版未实现流式结果。

# 最终本地安装包实施计划

目标：交付一个可双击使用的 DMG 安装包，复用已提交、已安装验证的64d9475应用，不改变产品设置或补全行为。

范围：当前用户安装，Apple芯片、macOS15及以上（实际二进制minos15.0；本机15.6验证）。原App的plist写14.0，安装器按实际二进制下限限制，不伪造修改已签名包。安装包不包含模型权重、Python、用户配置或在线凭据；当前机器复用原服务，其他机器需自备来源。

方案：独立原生AppKit安装器，一个“安装并打开”按钮，安装至~/Applications/CodexPromptAssistantPOC.app；无需管理员或开发工具。已有完全一致版本直接打开；其他版本保持并提示，禁止覆盖未知或正在运行的旧包。首次安装原子复制并验签、验证完整文件清单；失败保留现场或仅清理本次暂存。启动使用模型保护参数，不安装或修改LaunchAgent，不操作Codex或模型。

工作项：
1. Tools/Packaging/Installer.m：原生界面、固定路径安装、同版幂等、准确包校验、并发/符号链接/不同版保护；嵌入仅临时目录运行的自测入口。
2. Tools/Packaging/build_installer.py：从已核对干净App生成完整payload清单、编译签名安装器、复制说明到DMG；保留构建日志与交付清单。
3. 隔离自测、DMG只读挂载回读验签、载荷摘要一致、实际安装器界面与同版打开检查。
4. 输出至outputs/续言-0.2.0-macOS-arm64/，提供DMG、SHA256和简明说明。额外源码不默认提交，不推送、不对外发布。

发布边界：个人安装交付，ad-hoc签名、未Developer ID公证。无法冒充无拦截的公开发行版。干净账户授权和跨机器来源供给不能由临时目录自测替代；最终说明如实保留范围，交付不再只给计划。

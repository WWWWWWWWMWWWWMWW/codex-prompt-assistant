# 性能、异常处理、浮层体验及常用应用兼容性（2026-09-07）

## 已实施

- 流式累计内容未达到下一次展示长度门槛时跳过全文质量检查；空事件不再重复检查累计内容。每次真正展示和最终结果仍执行同一质量过滤。
- 对单次完成响应设置 256 KiB 缓冲上限，超限返回 `response_too_large`、取消网络任务并释放响应缓冲。错误／空结果清掉待展示片段；成功结果先交付最后的待展示片段，再执行最终回调，防止延迟片段覆盖最终状态。
- 候选最多三行，快捷键垂直居中；光标模式移到当前行下方，靠近屏幕边缘时调整位置，保留不抢焦点行为。小屏／非常长文本仍受三行上限限制。
- 对 WorkBuddy、飞书的已知 bundle ID，每个进程尝试一次运行时辅助功能启用。不读取额外正文、不修改敏感输入或远程授权策略。不支持该系统属性的应用继续走原本的聚焦检查。

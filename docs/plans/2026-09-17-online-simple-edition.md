# 在线精简版 0.3.0

用户范围已确认：交付新安装包；设置只保留在线续写、Key、多选范围；安装必须填写 Key。不增加公开发布、提交或服务变更。

实现：单页 AppKit 设置，Key 不回显；应用/精确网站多选立即保存。新的 OnlineCompletionScopes.v1 独立于旧规则，首次升级全部不选；Codex 同样受范围约束。永久保护及敏感输入规则优先，浏览器仅允许读取判断站点所需的元信息，正文仍先过策略。

在线版运行约束关闭本地模型、历史表达和自动历史扫描，保留旧偏好供回退。开关/Key/范围变化取消候选与请求；关闭在线续写清空已选择的任务上下文。保留当前任务上下文能力与 Tab/Esc 插入防护。

安装器要求固定在线服务的非空 Key；使用现有加密文件存储，独立保存到应用偏好域。运行中拒绝安装；仅接受精确 0.2.0 基线或同一新版。升级原子交换后保留旧包。未知旧版、改动包和损坏包拒绝覆盖。

交付采用真实 dirty 元数据、精确文件清单和源码快照，不执行未授权 Git 提交，不放宽通用 clean 更新器的门槛。通过关联回归、原生界面检查及 DMG 回读后交付个人安装包；真实 Key 由用户输入。

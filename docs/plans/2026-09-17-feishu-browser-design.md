# 飞书网页版支持

用户要求：截图中的 Chrome 飞书文档也能续写；沿用简洁三项设置。

采用共享“飞书（含网页版）”选项，复用现有客户端光标范围读取和中间插入。单独增加浏览器开关会让范围过宽；新增网站管理会增加设置，所以本次只扩展飞书这一项。

浏览器只做当前聚焦位置的元数据检查；从最近的 AXWebArea 获取页面网址，HTTPS 单层租户 feishu.cn 文档路由才映射到飞书授权。地址栏不属于文档 WebArea，未知主机和其他路由拒绝。页面 URL 参与只存在内存的字段身份，正文读取前后、显示和 Tab 前复核，以防跨站点/文档插入。

验收：范围联动与撤销；URL 正反例；中间插入保留后文；切站点/文档拒绝旧候选；真实 Chrome 文档只读核查；设置预览；回归及可安装包。实机浮层/实体 Tab 仅在实际操作后确认。

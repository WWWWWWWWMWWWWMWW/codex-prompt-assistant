# 保留承接关系的上下文实验

用户授权继续上下文材料选择优化，运行版保持 2026-09-10.1、双开/Terra。此前最后一条 user 的整体裁剪损失确认链，不重复该方案。

对照选择保留截至最近 user 的完整消息前缀，只排除后续 assistant 尾部。当前草稿显式指向助手回复/选项，或最近 user 很短、含指代时，保留完整历史。没有 user 时保持原样。规则只决定消息是否保留，不生成摘要，不把“好的”升级为事实确认，不重排正文。短消息阈值 12 个 UTF-16 字符，指代模式在实验前固定；非通用语义解析器。

备选方案是仅添加来源标签（已有 role 与未确认声明，收益证据不足）或再次调用模型抽取已确认事实（成本、延迟及审核可靠性尚未解决）。本轮先验证最小、可撤回的消息选择变化。

工具专用实现先通过确认链、选项引用、缺少用户、尾部解释及两路请求材料一致性检查。开发集使用此前 8 场景，每路基线/候选各两轮，共 64 次。每路候选关键事实/对象/范围偏移必须为 0、严格正确数量不低于同轮基线且至少改善一个原失败场景、ack/reference 不退化，才进入冻结的新样本验证。超时保留，不重试替换，不计正确停笔。

新样本提前固定，开发阶段不用于修改规则或提示词。两路不得合并成绩掩盖某一路失败。未通过不进入生产；若通过，再执行独立新样本对照与生产接入回归。用户未要求本轮安装，不重载任何服务，不改模型/开关，不提交或推送。

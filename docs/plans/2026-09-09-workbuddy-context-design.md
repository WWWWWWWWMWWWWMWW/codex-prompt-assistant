# WorkBuddy 当前会话上下文

用户要求：WorkBuddy 支持当前聊天的前文续写。范围为本地实现、合成验证和构建；不安装、重载、提交或修改用户补全开关。

## 方案

采用当前聚焦输入所属的 WorkBuddy `cb-chat` AX 子树。相比按标题查找本地历史文件，这条路径不需要猜测同名任务或扫描历史数据库；相比整窗文本采集，它能排除侧栏、其他聊天面板和工具输出。

读取器独立于 Codex 文件上下文。只对 `com.workbuddy.workbuddy` 的普通输入策略启用专用上下文模式；浏览器、搜索例外、敏感字段和其他应用保持原策略。读取正文前检查授权；采集过程中检查暂停、规则版本、焦点与耗时。根节点、用户 request ID 与选入正文共同构成仅内存的材料身份，未知结构或读取中切换归属返回无上下文。

只使用已加载的消息区。最近最多 6 条用户正文、2 段助手正文，共 3000 个 UTF-16 单元；不强制滚动历史，超预算不截断半句，宁可减少材料。排除生成中的助手行、回退作废消息、摘要用户消息和工具块。该限额不代表完整对话历史。

沿用 `CPAConversationContextSnapshot` 和候选生命周期：相同材料复用对象，变更时撤销依赖旧材料的请求/候选，清理两路缓存。插入签名包含材料身份和完整选入文本；Tab 的新读取也包含材料，因此未等到下一次轮询的会话切换仍可拒绝插入。本地与已有授权的远程使用同一份材料，不新增联网授权。

## 验收

合成树验证正文读取计数、角色、顺序、缺失结构、预算、流式排除和节点脱离；生产入口替身验证两路材料、同文异会话、迟到结果及 Tab 新鲜读取。实机另验 WorkBuddy 版本、AX 属性可用性、会话切换、生成中状态和 Tab 插入；代码/构建通过不能替代实机结果。

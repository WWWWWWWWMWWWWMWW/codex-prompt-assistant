# 真实服务只读检查实施范围

目标：为更新服务适配器补齐可复用的运行身份与保护参数读取，避免依赖临时脚本或旧启动日志。仅检查，不停止、启动、安装或联网。

实现 `Tools/Release/helper_runtime.py`：复用包验签/散列检查和进程映射读取；解析当前用户固定助手 label 的 launchctl 状态、程序、参数和已加载配置路径，核对磁盘配置、实际命令行及安装可执行文件映射。检查前后取两次快照，拒绝变化、重复/未知字段、错误 PID 或映射。仅支持目前已验证的直接执行和模型保护配置，其他启动方式保持未知。

测试加入发布准备套件，覆盖参数相似但不等、原模板/已加载配置不一致、配置和进程中途变化、映射错误及命令失败。使用当前已安装包实际运行只读 CLI，核对进程和偏好保持，记录验收结果。

运行身份通过不等于实时健康：旧启动日志、磁盘版本和 launchctl running 均不能证明输入监听仍可用。报告始终保留实时健康、停止确认与真实回退门槛；dirty 包只作当前本机只读检查，不放宽 clean 更新要求。工具不进入 app bundle，无需重建或重载；首页不增设置。

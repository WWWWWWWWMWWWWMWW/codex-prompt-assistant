# Codex 风格提示条设计

## 目标

把现有提示框调整为更轻、更现代的 Codex 风格悬浮条，同时保持提示位置、首帧立即显示、流式更新稳定以及 Tab/Esc 交互不变。

## 视觉方案

- 使用固定深色半透明中性背景，避免系统浅色模式让提示条与 Codex 深色界面割裂。
- 容器高度由 32pt 调整为 36pt，圆角提升为 10pt，使用低对比度细边框和轻量阴影。
- 建议正文使用系统字体与柔和高亮文字，不抢占输入内容的视觉焦点。
- 将快捷键提示拆成 `Tab`、`Esc` 两个独立键帽及“接受”“取消”说明，弱化为次级信息。
- 保持单行截断，不增加图标、动画、标题或状态区域。

## 布局与行为

- 输入框上方提示条沿用当前锚点和宽度算法，仅调整高度和内部间距。
- 光标侧提示沿用当前右侧定位方式。
- 流式文本变化不得改变同一锚点下的面板位置与尺寸。
- 面板继续禁止获取焦点、忽略鼠标并立即显示，避免影响输入与 Tab 接受。

## 验收

- 自动测试确认容器高度、圆角、边框、深色背景及两个键帽样式。
- 原有前台应用不切换、流式帧稳定和隐藏行为测试继续通过。
- 构建、代码签名及完整回归通过。
- 安装后以真实提示显示截图检查与 Codex 界面的视觉一致性；若当前无法触发候选，明确标记为未完成的视觉验收。

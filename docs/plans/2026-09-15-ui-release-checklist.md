## 执行顺序

1. 保持双开关与可选帮助的产品结构，明确全局暂停跨重启的用户含义。
2. 先固定首批用户、在线服务/模型供给、签名与安装路径，准备可追踪候选。
3. 完成实际新装、授权返回与失败回退，再以同一包执行声明宿主、质量和性能验收。
4. 小范围新人测试通过后再冻结公开资料；稳定版依据同一RC的观察结果放行。

```mermaid
  D --> E[真实授权与回退]
  B --> F[同包宿主验收]
  E --> F
  Q[质量与性能] --> S2[S2 小范围新人测试]
  F --> S2
  S2 --> S3[S3 公开测试]
  S3 --> S4[S4 稳定版]
```

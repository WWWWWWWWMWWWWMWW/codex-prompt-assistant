# 候选完整可读修正

## 已确认问题

240字是当前候选资源上限；浮层原本最多三行、文本高度57pt。204pt输入框生成180pt候选条，正文最小80pt又挤进快捷键区域。隔离AppKit复现测得正文需要50行/800pt，仅分配57pt；截图可见截断与Tab重叠。

## 本轮范围

- 保留原有非激活浮层与Tab/Esc；不增加设置或展开按钮。
- 窄输入框允许候选条更宽，正常候选条使用至少360pt，受实际屏幕可见区域约束；短候选仍保持紧凑高度。
- 用文本控件的实际布局测量全文高度，不设三行上限；快捷键与正文保持独立区域。
- 如果候选无法完整放进屏幕，隐藏浮层，发布动作返回失败并清理接受状态，使下一条合格候选仍可显示。
- 不改候选生成、语义过滤、240字资源上限、来源开关或读取策略。

## 验收

先保留修改前失败与截图，再测240字中文、显式多行、窄输入框、靠右边界、超屏隐藏及恢复。用独立TextKit测量检查正文空间，并检查快捷键互不重叠；生命周期回放确认隐藏候选不能接受且不占据后续显示。完整应用回归、构建验签、备份安装及运行身份核对后交付。物理Tab/Esc、多屏和真实中文组合输入不因隔离测试通过而自动通过。

# 编号选项格式兼容

用户授权先安装 .2，再继续优化。已完成安装；本工作包只构建下一候选，不再重载助手。

已确认：现有解析器要求动作部分全为汉字，仅删除整份列表末尾的句号；逐项句号、空行和 Markdown 加粗都会失配，退回仍可能改意的模型路径。

采用局部格式解析：保留原始 180 字上限，CRLF 转 LF，忽略纯空白行；仍完整解析全部非空内容和连续的 2–3 项编号。每项允许一个末尾中文句号，以及整个动作的成对 ** 加粗（句号可在加粗内或外）。不移除内容中的任意标记，不寻找列表子串。汉字动作、动词/条件校验、用户明确选择、相邻消息、草稿句首、共同过滤及生命周期约束保持。

不采用跨助手确认消息向后找旧选项：可能引用过期范围；不采用泛化 Markdown 渲染后取文本：容易吞掉引用、链接、代码与附加限制。当前只扩展可机械验证的排版形式，未覆盖的形式仍走原路径，不承诺整体停笔。

先冻结新格式和反例并复现未命中，再修改协议。验证条件/附注/否定、多选、漏项、重复、错配加粗、引用/代码/链接、草稿修订仍不提取；两路客户端命中无 HTTP、模型冷却状态不变；旧 27 例全部保留期望。执行协议/客户端及应用回归、独立禁网回放、候选构建/验签。无真实模型或实机输入测试，不宣称通用语义质量提升。

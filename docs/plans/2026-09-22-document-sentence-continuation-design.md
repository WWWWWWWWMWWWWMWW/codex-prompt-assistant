# 普通文档输入的句间续写

2026-09-22。用户确认继续修复手动句号后不续写。上一轮只向 Tab 接受后的文档传递阶段，普通输入仍使用原模板。结构门并不禁止句号；现场普通文档请求返回空内容。

## 范围

仅远程文档末尾增加共同句间续写策略，普通输入和接受后共用；接受后仅保留真实阶段说明，不再重复一套更强的停笔规则。聊天、中间插入、小型本地模型保持既有模板。手动输入不得伪装成接受，不调整调度、超时、质量过滤或重试。

允许补充原文条件/动作/结果之间可推导的关系，句号不代表条目结束；一般说明允许自然展开。区分业务范围限制和作者限制输出范围。原文缺少另一对象规则不得套用相似机制，不新增业务事实。明确停止或只有待定事项仍返回空。

## 验证门槛

使用固定合成规则复现，不保存截图中的真实业务原文。旧/新对照保留全部失败，包括错误概括分支、推断未知任务池。最终生产客户端对同一两分支句号规则独立请求三次，核对关系是否正确；另有一般说明、明确范围和缺参数边界。协议测试证明普通/接受后共享策略且其他模式不变，生命周期回放证明手动句号按普通文档请求并能显示合格候选。然后完整测试、构建验签、备份安装和运行身份/配置保持检查。真实文档显示必须单列，不以合成代替。

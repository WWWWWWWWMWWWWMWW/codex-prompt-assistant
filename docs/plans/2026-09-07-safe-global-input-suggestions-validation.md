## 现场发现与修复

1. 应用切换使异步 AX 探测过期，却未释放 busy 标记，回到相同应用可能永久静默。新增失败回归后，在前台边界同时清除 busy 与目标信息；回归和实机重新探测通过。
2. 仅本地策略原先没有拦住远程运行调度。17:10 的一条无敏感测试句曾触发已配置远程服务；立即停止旧助手，新增失败回归并修复定时调度、启动、实际发送及结果显示门禁。非 Codex 模型上下文显式为空。之后 TextEdit、已授权站点与搜索测试均为本地请求。该修复前远程候选不计入本地验收。
3. Computer Use 的定向 Tab 只插入制表符，未经过全局快捷键，不能算实测失败或成功；该制表符已删除，最终以授权后的原生全局按键与文稿读回为准。

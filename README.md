# Codex 智能提示助手

macOS 输入框旁的提示词续写助手。沿用用户正在写的需求，提供可插入的后缀；Tab 接受，Esc 取消，由用户自己发送。

运行方式与本机远程开关见 [当前状态](docs/status.md)；本机配置不代表新安装默认值。对外分发、统一产品名与安装向导尚未完成。

## 本机开发

要求 macOS 14+、Xcode Command Line Tools（clang / make / codesign）、Python 3、Node.js（WPS 离线测试）。

```sh
cd /Users/hcm-b0263/Desktop/Codex智能提示助手
make help
make -B app
git diff --check
```

构建生成 `build/CodexPromptAssistantPOC.app`，不会安装或重载。`make check-offline` 汇总构建身份与五组核心测试并禁止网络访问；仍会触及测试钥匙串项及共享诊断日志，运行前先读开发文档的副作用说明。实机验收另行执行。涉及运行程序的操作先确认当前进程和草稿状态。

## 使用边界

状态栏按应用或精确站点选择推荐、启用普通输入、关闭。产品要求敏感与拒绝场景在读取正文前受保护，但 Codex 专用路径尚未统一满足，详见架构与当前缺口。普通应用实时采集及模型对话上下文限当前输入，历史表达候选可能跨任务匹配。空输入或没有合适续写时允许不显示候选。

状态栏 → **设置智能补全…** 中，“本地补全”和“远程补全（联网）”可独立开关，支持仅本地、仅远程、同时开启和全部关闭，立即生效并记住选择。切换会清除旧候选，返回输入框后重新检查当前草稿。关闭本地会停用本机模型请求及历史表达候选，常驻模型进程保留；远程开关只对已有联网权限的应用/站点生效，仅远程模式下不在本地场景生成候选。API Key 和模型的修改仍需点击“保存服务配置”。

WPS 仍是实验集成。旧阶段名称 `POC`、bundle ID 和服务标识暂时保留，避免权限与数据迁移干扰。
